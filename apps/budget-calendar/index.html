Budget Calendar

Budget Calendar puts income and expenses on the days they actually happen, so a month reads like a calendar instead of a spreadsheet. It runs right here in your browser — nothing to install, no account to make, and every number stays on your own machine.

What you are using

The real thing, not a mockup or a video. Set a budget and a date range, then put expenses on the days they happen and watch the daily allowance absorb them.

  • Your numbers stay here. Entries are saved in this browser's own storage. Nothing is sent to LITrenders — there is no server to send it to.
  • Nothing to install. No account, no sign-up, no email address.
  • Export whenever. The export button writes a JSON file to your downloads, and the same file imports back on any other device.
  • No ads. This page carries none.

Clearing your browser data clears the budget with it. Export first if you want to keep it.

What it is

A month of money, at a glance.

  • Calendar-first, not ledger-first
    Every entry sits on its date, so you can see the shape of a month before it happens.
  • Multi-currency
    Keep entries in more than one currency with up-to-date conversion.
  • Multiple languages
    Built for the languages most people actually budget in.
  • Local by design
    Entries are stored on your device. There is no account, no sync server and no analytics.
  • Runs onAny modern browser, phone or desktop
  • StorageYour own device — no account, no sync server
  • NetworkOnly to refresh exchange rates — everything else works offline
  • DeveloperLITrenders (Bruno Camargo)

How it is built

One interface, no build step.

Budget Calendar's interface is a single HTML file with no framework and no dependencies. It runs straight from this page, and the same file drops into a native shell when there is a phone build to wrap it in.

  • Exact arithmetic
    Money is held as whole minor units and rounded once, at the point it is displayed.
  • Currencies and languages
    Twelve languages and a bundled exchange-rate table, refreshed from a public rate service when a connection is available.
  • Storage you control
    The page keeps your data in the browser and hands it back as a JSON file whenever you ask. No copy ever leaves your device.
  • A palette of its own
    The product is not the brand. Budget Calendar leans on colour to tell grocery, other and savings apart, so it keeps its blue inside the frame while the page around it stays in the studio's ink and paper.
  • Light and dark
    The app follows your system setting, and the moon button in its header overrides it. Your choice is remembered in this browser.
