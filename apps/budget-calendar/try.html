Try it in your browser

Budget Calendar is a web interface wrapped in a native Android shell. This is that interface, running here — the same code that ships inside the app, dressed in the studio's colours, with nothing to install and no account to make.

What you are using

The real thing, not a mockup or a video. Set a budget and a date range, then put expenses on the days they happen and watch the daily allowance absorb them.

  • Your numbers stay here. Entries are saved in this browser's own storage. Nothing is sent to LITrenders — there is no server to send it to.
  • Nothing to install. No account, no sign-up, no email address.
  • Export whenever. The export button writes a JSON file to your downloads, and the same file imports back into the Android app.
  • No ad here. The Android build carries one banner at the bottom; this page has none.

Clearing your browser data clears the budget with it. Export first if you want to keep it.

How this page exists

One interface, two shells.

Budget Calendar's interface is a single HTML file with no framework and no build step. On Android it runs inside a native shell that adds the system file picker, backup handling and the ad banner. On this page the same file runs in your browser, and the parts that need Android quietly stand down.

  • Same arithmetic
    Money is held as whole minor units and rounded once, at the point it is displayed — identical here and on the phone.
  • Same currencies and languages
    Twelve languages and a bundled exchange-rate table, refreshed from a public rate service when a connection is available.
  • Different storage
    The phone keeps your data in the app's private storage; this page keeps it in the browser. Neither copy ever leaves your device.
  • Different colours
    On the phone the app wears its own blue. Here it takes the studio's ink and paper, so the page reads as one piece. A build script applies the theme, so the two never drift apart.
  • Runs onAny modern browser, phone or desktop
  • NetworkOnly to refresh exchange rates — everything else works offline
  • Android appIn development — not yet on Google Play
